ETB Save Manager — Save File Manager for Escape The Backrooms

ETB Save Manager is a free, open-source save file manager for the horror game Escape The Backrooms. Version 3.4.0 (Archive Edition) gives you full control over your saves: create, edit, back up, duplicate, hide, soft-delete, and restore them from a fast desktop app built with Tauri 2.0 for Windows 10 and 11. It is released under the MIT license, works completely offline, and sends no telemetry.

What is ETB Save Manager?

Escape The Backrooms stores your progress in local save files, and losing one means losing dozens of hours of exploration. ETB Save Manager is a declassified archive manager for those saves. Instead of digging through folders and hoping a file copy worked, you get a searchable library of every save — with favorites, batch operations, and full undo/redo. A 3-step creation wizard lets you start a new run at any of the game's 55 levels across its 4 endings (Wrong Door, Empty City, The Suburbs, The Pink House), configure difficulty, and edit a 12-slot inventory stocked from 25 items including the Flashlight, Almond Water, and the Flare Gun. Mod management with UE4SS/NSU support rounds out the toolkit.

Every operation happens on your machine. There is no account, no cloud sync, and no installer bloat — the Windows x64 build is about 4.7 MB.

Key features

Full save management

Create, edit, copy, hide, soft-delete, and restore saves. Mark favorites, run batch operations, and rely on full undo/redo if a change doesn't look right.

3-step creation wizard

Quick Create or Standard mode — pick from 55 levels across 4 endings, configure difficulty, and edit a 12-slot inventory before you ever load the game.

10 built-in themes

Light and Dark modes plus 8 vibrant palettes: forest, lavender, mint, ocean, peach, rose, sky, and sunset.

Trilingual UI

The complete interface is available in English, 简体中文, and 繁體中文.

Virtual scrolling

GPU-accelerated virtual scrolling keeps the archive list smooth even with thousands of saves, loading entries incrementally.

Performance monitor

Built-in FPS, memory, and animation-quality diagnostics let you tune GPU rendering and effect budgets in real time — useful on older hardware.

Smart resource scheduling

The app detects what you're doing and dynamically allocates CPU, rendering, and I/O budgets through a priority-based background task queue with real-time FPS and memory feedback loops.

Frequently asked questions

Is ETB Save Manager free?

Yes. It is completely free and open source under the MIT license, with the full source code available on GitHub.

Which platforms are supported?

Windows 10 and 11, with native installers for x64, x86, and ARM64. The app is built with Tauri 2.0, which keeps the binary small and fast.

How many levels and endings does the wizard support?

All 55 levels across the game's 4 endings — Wrong Door, Empty City, The Suburbs, and The Pink House — plus difficulty configuration and a 12-slot inventory editor.

Does it need an internet connection or send data anywhere?

No. The app is offline-first and works entirely on your local save files. There is no telemetry of any kind.

What languages does the interface support?

English, Simplified Chinese (简体中文), and Traditional Chinese (繁體中文).

Does it support mods?

Yes. ETB Save Manager includes mod management with UE4SS and NSU support, so you can keep mods and saves organized together.
